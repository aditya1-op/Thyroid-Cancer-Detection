# Results

This folder contains the experimental results and visualizations generated during the thyroid cancer recurrence prediction study.

Planned outputs include:

- Model performance comparison
- Confusion matrices
- ROC curves
- Feature importance
- FSRO selected features
- SHAP analysis
- LIME explanations
- Partial Dependence Plots (PDP)
- Permutation importance
- Counterfactual explanations using DiCE
- Residual analysis
