# Dataset

This folder contains information about the dataset used for the thyroid cancer recurrence prediction project.

The dataset is the Differentiated Thyroid Cancer Recurrence dataset.

The dataset contains 383 patient records and 16 predictor variables, with `Recurred` as the target variable.

The dataset is included in this repository for research and educational purposes.

Please refer to the original dataset source for the dataset citation, licensing, and usage terms.
